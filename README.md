## Project Overview
This is a fully responsive portfolio website that adapts seamlessly across mobile, tablet, and desktop. It includes sections for Home, Services, Projects, About, and Contact, navigable via a sticky top navbar with a hamburger menu on small screens.

## Features
- **Responsive Design:** Works across all screen sizes.
- **Sticky Navigation Bar:** Smooth scrolling with a mobile hamburger menu.
- **Hero Section:** Personalized intro with a call-to-action button.
- **Services Section:** Cloud Infrastructure, CI/CD Automation, Containerization, and Infrastructure as Code.
- **Projects Section:** Highlights recent DevOps/Cloud projects with descriptions and images.
- **About Section:** Personal bio plus a downloadable resume.
- **Contact Section:** Phone, email, and address cards.
- **Footer:** Branding and social media links.
